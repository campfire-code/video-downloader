# 无需联网的验收视频

用本机 ffmpeg 生成一个自制测试视频，并在本机起一个 http 服务：

```bash
ffmpeg -y -f lavfi -i testsrc=duration=6:size=640x360:rate=25 -f lavfi -i sine=frequency=440:duration=6 \
  -c:v libx264 -pix_fmt yuv420p -c:a aac -shortest sample.mp4
python3 -m http.server 18765   # 在 sample.mp4 所在目录执行
```

然后在应用里粘贴 `http://localhost:18765/sample.mp4`。
